# LithoAI

### Machine Learning-Based Defect Prediction in Semiconductor Manufacturing

## Overview

LithoAI is an experimental research project exploring the application of machine learning techniques to semiconductor manufacturing defect prediction and process analysis.

The project investigates how data-driven models can be used to identify patterns associated with manufacturing defects and evaluate their predictive performance.

## Research Objectives

- Explore machine learning approaches for semiconductor manufacturing defect prediction.
- Investigate data preprocessing and feature selection techniques.
- Compare the performance of different classification models.
- Evaluate model reliability under class imbalance and distribution shifts.
- Analyse the limitations and potential applications of data-driven prediction methods.

## Current Development Status

**Phase:** Experimental development and model evaluation.

The current work focuses on exploring machine learning models using the SECOM semiconductor manufacturing dataset.
